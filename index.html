MapReduce Search Engine

Course Project · Fall 2024

A search engine that indexes a document collection with a distributed MapReduce pipeline and serves ranked results through a web interface.

I implemented a multi-stage MapReduce pipeline in Hadoop to analyze document text and build an inverted index, then developed an index server and a search front end that handles queries and displays results. Documents were given a query-dependent tf-idf score and a query-independent PageRange score which factored into their final ranking.

Python Hadoop MapReduce Flask JavaScript REST API

Cryptographic Attacks

Course Project · Winter 2024

A set of attacks exploiting weaknesses in widely used cryptographic schemes, carried out against course-provided targets.

I wrote Python programs that perform a length extension attack on SHA-based MACs, generate MD5 hash collisions, decrypt CBC-mode ciphertext with a padding oracle attack, and forge RSA signatures using Bleichenbacher’s attack. Each attack was built to run efficiently.

Python SHA MD5 CBC RSA

LC2K Assembler & Simulator

Course Project · Winter 2024

An assembler and instruction-level simulator for LC2K, a minimal RISC instruction set architecture.

I wrote, in C, an assembler that translates LC2K assembly into machine code supporting R-, I-, J-, and O-type instructions, plus a simulator that executes it. I then used the toolchain to write an optimized LC2K program that multiplies 15-bit numbers.

C Assembly Computer Architecture
